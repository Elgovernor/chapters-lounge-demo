# Chapters Lounge demo

Website demo for Chapters Lounge & Hangout, Ladysmith. Built by GBTechsolutions.

Static HTML, CSS and JavaScript. Includes events and meals galleries, image lightbox, venue contact links and a table request composer. Table requests require the visitor to send the prepared message to the venue.

Images are original Facebook photographs and promotional artwork. Past offers are labelled historical. Confirm venue details and permission before adopting this as the official website.

Deploy with the Other framework preset; no build command is required.
