BEFORE YOU VISIT
GOOD TO KNOW.
A few answers to help you plan. Confirm event-specific arrangements directly with the venue.
Is there an age restriction?
The venue’s event posters specify 18+. Bring identification and confirm admission requirements for the event you’re attending.
What is the dress code?
A current general dress code has not been confirmed. Check the event announcement for themed attire and contact the venue before visiting.
Can I bring a cooler box?
Some past Xtension events advertised cooler-box access before 17:00 for R100. This is a historical arrangement, not a standing policy. Ask about the rules and charge for your specific event.
Where can I park?
Use the directions link to reach Murchison Street. Contact the venue for recommended parking, accessibility and drop-off arrangements.
Does a table request guarantee a reservation?
No. The venue must reply and confirm availability. Ask the team about entry fees, table arrangements and any deposit before making plans.
Can I get the current menu?
Use the menu enquiry button or call 036 631 2337. Ask for current prices, kitchen hours and dietary options.
